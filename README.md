# Smiley Store

A premium, high-performance storefront for hardware, gaming software, and professional laptops.

## Key Features
- **Mobile-First Design**: Fully responsive layout optimized for devices from 320px to 1024px+.
- **Quick View System**: Interactive product modals with multi-image galleries and spec sheets.
- **Cyberpunk Aesthetic**: High-end UI featuring neon accents, glassmorphism, and fluid animations.
- **Secure Checkout**: Multi-protocol payment portal supporting Credit Cards, PayPal, Crypto, and Mobile Money.

## Project Structure
- `home.html`: Main landing page with live advertising ticker.
- `products.html`: Comprehensive catalog for all categories.
- `hardware.html` & `laptops.html`: Specific hardware landing pages.
- `login.html`: Secure gateway access (Credentials: `admin` / `admin`).
- `payment.html`: Encrypted payment gateway interface.

## Setup & Deployment
1. Clone the repository.
2. Open `login.html` in any modern web browser.
3. To host via GitHub Pages, go to **Settings > Pages** in your GitHub repository and set the source to the `main` branch.
